# Лабораторная работа №4. Правило трёх

## Назначение класса

`Matrix` — динамическая матрица целых чисел произвольной размерности. Класс сам владеет выделенной памятью и корректно управляет ею при создании, копировании, присваивании и уничтожении объекта.

Поля класса находятся в `private`:

```cpp
int** data_;
int rows_;
int cols_;
```

## Правило трёх

В классе реализованы:

1. **Деструктор** `~Matrix()` — освобождает память.
2. **Конструктор копирования** `Matrix(const Matrix& other)` — выполняет глубокое копирование.
3. **Оператор присваивания** `Matrix& operator=(const Matrix& other)` — освобождает старую память и копирует новые данные.

### Конструктор копирования

Создаёт новую матрицу такого же размера и поэлементно копирует значения. Указатели `data_` у исходной и новой матрицы разные, поэтому изменение копии не влияет на оригинал.

### Оператор присваивания

Работает в таком порядке:

```cpp
if (this == &other) {
    return *this;
}

freeMemory();
copyFrom(other);
return *this;
```

- защита от самоприсваивания не даёт освободить память до её копирования;
- возвращается `Matrix&`, поэтому работает цепочка `d = e = a`;
- старая память освобождается до выделения новой.

## Домашнее задание: рефакторинг

Работа с памятью вынесена в три приватных метода:

```cpp
void allocate(int rows, int cols);
void copyFrom(const Matrix& other);
void freeMemory();
```

- `allocate` — единственное место с `new int*[...]` и `new int[...]`;
- `copyFrom` — единственное место с двойным циклом копирования значений;
- `freeMemory` — единственное место с `delete[]`, обнуляет `data_`, `rows_`, `cols_`.

Все конструкторы, деструктор и `operator=` используют эти методы, поэтому дублирования кода нет.

## Почему деструктор не освобождает одну память дважды

- при копировании создаётся **собственная** память для каждого объекта;
- `operator=` сначала освобождает старую память объекта, затем выделяет новую;
- самоприсваивание `a = a` обрабатывается отдельно и не приводит к освобождению памяти;
- `freeMemory()` после освобождения ставит `data_ = nullptr` и размеры в ноль;
- пустая матрица не владеет памятью, и повторное освобождение безопасно.

## Что демонстрирует программа

1. Создание матрицы `a(3, 4)` и заполнение случайными числами.
2. Копирование `Matrix b = a` через конструктор копирования.
3. Изменение `b` — матрица `a` остаётся прежней.
4. Присваивание `c = a` с предварительным освобождением памяти `c`.
5. Цепочку `d = e = a`.
6. Самоприсваивание `a = a`.
7. Копирование и присваивание пустых матриц.

## Особенности

- Отрицательные размеры приводят к исключению `std::invalid_argument`.
- Размер `0` создаёт пустую матрицу `0×0` без выделения памяти.
- `get()` и `set()` проверяют индексы и выбрасывают `std::out_of_range`.
- Методы `get`, `print`, `sum`, `getRows`, `getCols`, `transpose` объявлены `const`.
