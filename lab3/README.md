# Лабораторная работа: класс Matrix

## Назначение класса

`Matrix` — матрица целых чисел произвольной размерности. Класс инкапсулирует данные: снаружи доступны только методы, а поля `data_`, `rows_`, `cols_` находятся в `private`.

## Что демонстрирует программа

1. Создание четырёх матриц разными конструкторами.
2. Вывод единичной матрицы `m2`.
3. Заполнение `m2` по формуле `i * j`.
4. Заполнение `m3` случайными числами.
5. Копирование `m3` в `mm`:
   ```cpp
   Matrix mm = m3;
   mm.print();
   ```
6. Ввод `m4` с клавиатуры.
7. Сумму элементов `m3`.
8. Транспонирование `m3`.
9. Обработку исключений для отрицательной размерности и выхода за границы.

## Важно: копирование и завершение программы

По условию домашнего задания конструктор копирования и `operator=` пока **не реализованы**. Поэтому строка

```cpp
Matrix mm = m3;
```

выполняет поверхностное копирование: `mm` и `m3` содержат одинаковые указатели на одни и те же строки матрицы.

В конце программы сначала вызывается деструктор `mm`, который освобождает память `m3`, а затем деструктор `m3` пытается освободить её повторно. Это приводит к двойному удалению памяти и аварийному завершению программы **после вывода всех результатов**. Это ожидаемая демонстрация проблемы; её нужно описать в отчёте. Исправление появится позже — при изучении конструктора копирования и оператора присваивания.
- Для пустой матрицы (`0×0` или хотя бы одна размерность равна нулю) память не выделяется, `data_` равен `nullptr`.
